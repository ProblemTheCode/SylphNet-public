## How to Use

### v2rayN (Windows)
1. Open v2rayN
2. Go to **Subscription Group** then **Add**
3. Paste the subscription link above
4. Click **OK** then **Update Subscription**

### Nekobox / Shadowrocket / V2RayNG
1. Open app settings
2. Add new subscription
3. Paste the link
4. Update and enjoy

## Why SylphNet?

## Config Naming Format

```
@SylphNet | 1405-06-15 #1
@SylphNet | 1405-06-15 #2
@SylphNet | 1405-06-15 #3
...
```

- **@SylphNet** - Channel name
- **1405-06-15** - Iranian (Jalali) date
- **#1, #2, #3** - Sorted by ping (best = #1)
